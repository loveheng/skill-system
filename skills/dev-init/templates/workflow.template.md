## 读码纪律（省 token 与正确性兼得）

文档比代码省 token，但文档**有损且可能失真**——照文档下手可能建在错误前提上。三段式：

| 阶段 | 动作 | 成本量级 |
|---|---|---|
| ① 文档建图 | 先读索引落点 + memory 决策 + devlog 变更，拿「为什么 / 边界 / 落点」 | 几十~几百 token |
| ② 定向读码 | LSP / grep 只读相关符号与区域，**禁整文件通读** | 几百 token/次 |
| ③ 关键断言实证 | 文档「已实现」结论动手前抽查一处代码确认；行号引用须实测（会漂移） | 一次性 |
