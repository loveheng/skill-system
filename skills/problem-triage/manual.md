# 排错说明书（给人类用户）

> **这是什么**：当 AI 在排查重大/疑难问题时，会按排错协作协议与你协作。这份说明书只讲**你的部分**：你会收到什么、你该做什么、哪些红线你必须守。协议细节（流程怎么走、AI 怎么判断）**以 `problem-triage/SKILL.md` 为唯一事实源**，此处不重复——AI 改协议，本说明书不必跟着改。

## 1. 你会收到什么

AI 停止闷头排查时，会向你抛一份**交接单**（格式细节见 SKILL §3.1）：

```
[已排除]      已证实不成立的假设（各附证据）——不用再怀疑这些方向
[待验证假设]   当前最可能的 1~3 个错误方向，每条标注侧别
[需要用户]     具体到可直接执行的资源/操作/决策请求（优先「代执行」：给你一条命令 + 预期输出，跑完原样回传）
[当前方案]     AI 已有倾向方案时的结论 + 依据 + 置信度（高/中/低）
```

三种触发场景（重大故障分段推进 / 熔断给还原选项 / 长排查抛交接单）见 SKILL 触发归口与 §3——你只需要知道：**收到交接单 = 轮到你校正节奏**。

## 2. 你的响应（随时发、随时生效，AI 不等你）

交接单抛出后 AI 会**继续跑下一节拍**，你的回复是校正信号：

| 你的响应 | AI 的动作 |
|---|---|
| 不回复 | AI 按自己的节奏继续节拍（默认行为） |
| 补充信息 / 代执行操作 | 整合后进入下一节拍 |
| **否决**（「假设 X 不对，因为……」） | 移入已排除，重新收敛候选——你的经验否决是最有价值的输入 |
| 改方向 / 重排优先级（「先查这个，影响付费用户」） | AI 按业务权重重排假设，遵从执行 |
| **挂起**（「先停在这等我日志」「等我确认再继续，最多半小时」） | AI 停在当前节拍等你——进展已存档不丢，到期限或你回复后继续；不说到期就一直等。**只有你能发起挂起**，AI 不会自己停下来等 |
| 对 `[当前方案]` 表态 | 认可 → AI 收尾落实；质疑 → AI 给对比依据或换向 |

**两处例外会真正停下来等你**：下一步是高危/不可逆操作（还原、生产变更），或 AI 要执行大改动——此时必须拿到你的显式确认。

## 3. 如果选择「还原优先」

完整五步（锚定 → 沙盘推演 → 快照 → 可逆还原 → 变更复盘）见 SKILL §3.3。你的三个决策点：

1. **「最后一次正常」以你的口述为准**——AI 提议的候选（最近验证通过的 commit / tag）必须经你确认才作数；
2. **沙盘推演能锁定嫌疑时，AI 会请你确认跳过真实还原**——推演不收敛或你要求实证才真还原；
3. **复盘结论与修复方案先到你手上再动手**，不会先斩后奏。

## 4. 八侧速查（判断问题大概在哪）

八个侧别（代码/数据/环境/时序/意图/第三方/资源/发布）的定义、特征信号与各侧人类需要的背景，见 SKILL §1/§2——`[待验证假设]` 每条尾部已标侧别，按侧别备背景即可。

**两个特别提醒**：
- **发布侧**（线上跑的不是你以为的代码）：如果你发现「线上行为与本地同 commit 不符」，主动说「检查一下发布」——这是最容易被误导向环境侧空转的一类；
- **意图侧**：若你看到 `(意图侧)` 标注，说明 AI 怀疑「实现的是错误的理解」——此刻最有效的动作是**一句话重述你的真实预期**，而不是提供任何技术信息。

## 5. 你的三条红线（AI 不会越过，但你要知道）

1. **不可恢复的 git 操作**（reset --hard / clean -f / 强推）必须你显式授权具体命令；
2. **生产/数据破坏性操作**（删表/清队列/覆盖分支）必须列影响范围后等你批准；
3. **AI 只给步骤不硬试不可达环境**：生产变更、内网调试这类操作，AI 会给你操作步骤与预期输出，由你执行后回传结果——回传时带上原样输出，别只说「成功了/失败了」。

## 6. 一图总览

```
问题发生
  ├─ 小问题 → 常规修复（你正常下指令即可，无特殊流程）
  └─ 重大/疑难 → AI 分段推进（接力循环，协议见 SKILL §3.2）
        ├─ 修 2 次失败 / 重大故障 → 「还原优先？」→ 你选 → 五步流程（§3.3）
        └─ 长排查 → 交接单（已排除/假设+侧别/需要你/当前方案）
               └─ 你按第 2 节响应（或干脆不回，AI 继续跑）→ 直到解决验收
                     └─ 解决验收三样齐（SKILL §3.5）→ 快照退场 → 收工
```

> 全程你只需要做三类事：**确认锚点、提供人侧独有的信息/操作、在方案上拍板**。其余（自查、推导、可逆操作）AI 负责且不会让你重复劳动。
